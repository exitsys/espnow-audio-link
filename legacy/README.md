# legacy：旧版链路（ADPCM + UDP）

这里是不再维护的两套代码，保留下来是为了对照设计演进，**不建议直接使用**。

| 目录 | 内容 |
|---|---|
| `tx/` | 发射端：正弦/本地音源 → **ADPCM 压缩** → UDP over WiFi |
| `rx/` | 接收端：UDP → ADPCM 解码 → I2S |

与现役版本（`tx_uac/` + `rx_uac/`）的区别：

| | legacy | 现役 |
|---|---|---|
| 传输 | UDP over WiFi（需 AP、需 HELLO 注册） | ESP-NOW 单播，硬件 ACK |
| 音频 | ADPCM 压缩（4:1） | 原始 PCM，不压缩 |
| 音源 | 内部正弦波 / 本地文件 | USB 声卡（UAC2），直接接主机 |
| 抗丢包 | 无 | PLC 复读衰减 + 水位闭环重采样 |
| 断线自愈 | 需要重新握手 | 无需握手，发包即恢复 |

保留的原因：ADPCM 版本在弱信号下抗丢包更好（码流只有 1/4），如果将来要在
远距离或强干扰环境用，这段代码还有参考价值。算法层面的教训见根目录 `TUNING.md`。
